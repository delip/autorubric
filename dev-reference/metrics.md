### Inter-judge Agreement (Krippendorff's α + Fleiss' κ)
`compute_metrics()` reports inter-judge agreement (judges vs. each other, independent of ground truth) for binary, ordinal, nominal criteria, populated only when the report is an **ensemble with ≥2 judges and ≥2 items** — else both stats are `None`. Per-vote errors (`JudgeVote.error` / `MultiChoiceJudgeVote.error`) are excluded so only genuine judgments count.

**Krippendorff's α (`krippendorff_alpha`) is the general, recommended statistic** — handles unequal/missing raters and is **level-aware** (`level="ordinal"` for ordinal — distance-aware — vs `level="nominal"` for binary/nominal), fixing Fleiss's order-ignoring. `_compute_krippendorff_alpha()` builds a per-criterion **reliability matrix** (rows = judges in `judge_scores` order, columns = items; cell = judge's numeric code, or `np.nan` when errored/excluded/absent). Binary codes: MET=0, UNMET=1, CANNOT_ASSESS=2 (only under `as_category`; `exclude` → `np.nan`, `as_unmet` → UNMET). Multi-choice cell = `selected_index` (genuine NA included). α uses ALL items (missing handled), no complete-case dropping. Guards `<2` units / `NaN` / exceptions → `None`.

**Fleiss' κ (`fleiss_kappa`) is the classic fixed-rater nominal measure, retained complete-case.** statsmodels requires uniform raters per subject, so `_build_fleiss_row()` includes a subject ONLY if its counted votes sum to exactly `n_judges` (items with any errored/excluded/CA-under-`exclude` vote drop from the Fleiss matrix but stay in α as missing cells). `_compute_fleiss_kappa` guards `NaN` → `None`. Binary categories follow `cannot_assess` (`exclude`/`as_unmet` → 2 columns, `as_category` → 3 incl. CANNOT_ASSESS); multi-choice uses one column per option, genuine NA as an ordinary column. Both `fleiss_kappa` and `krippendorff_alpha` are **ground-truth-independent** (inter-judge only), so they are computed for a criterion even with **zero GT-paired samples**: the binary/ordinal/nominal per-criterion empty-data branches all call `_compute_fleiss_kappa(fleiss_matrix)` and pass `krippendorff_alpha` through (only the pred-vs-truth metric *values* go `None` there) — aligned ordinal/nominal, which previously hardcoded `fleiss_kappa=None`.

`krippendorff` (numpy-only) and `statsmodels` are both **hard dependencies**; the import guards (`HAS_KRIPPENDORFF` / `HAS_STATSMODELS`) in `_compute.py` stay for safety.

Both stats appear in `MetricsResult.summary()` and `to_dataframe()` (`_types.py`). `to_dataframe()` always emits `krippendorff_alpha` / `fleiss_kappa` columns (`None`/`NaN` where N/A — aggregate/judge rows, single-judge criteria). `summary()` appends `Kripp-α` (recommended, leads) + `Fleiss` columns to a criterion-type table only when ≥1 criterion in that group has a non-`None` value (single-judge output unchanged); per-criterion `None` renders as `n/a`.

**Framework principle: prediction-vs-ground-truth categorical agreement is reported as Cohen's kappa across the board** — binary `CriterionMetrics.kappa` (unweighted, possibly 3-class under `cannot_assess="as_category"`), ordinal `OrdinalCriterionMetrics.weighted_kappa` (quadratic-weighted), nominal `NominalCriterionMetrics.kappa` (unweighted); the orthogonal abstain decision uses `NAStats.na_kappa` ({NA, not-NA}) and the binary parallel `CannotAssessStats.ca_kappa` ({CANNOT_ASSESS, not-CANNOT_ASSESS}). All are chance-corrected and Landis & Koch interpretable via `KappaResult.interpret_kappa`. **Distinct** from inter-judge agreement (above), which uses `krippendorff_alpha` + `fleiss_kappa`. New pred-vs-truth categorical agreement metrics should land kappa-shaped, not as ad-hoc proportion metrics.

### Aggregate / per-judge scalar metrics: None when undefined, and type-handling parity
**A metric is `None` when genuinely undefined / not-applicable, never a fake `0.0`** (see *Undefined → None*). Aggregate scalars `criterion_precision`/`recall`/`f1` are the **binary MET-vs-rest** metric → `None` for a multi-choice-only rubric (no MET class; multi-class P/R/F1 lives in each criterion's `per_option`). `criterion_accuracy` generalizes (binary label accuracy when ≥1 binary criterion exists, else multi-choice exact-match), `mean_kappa` is the mean of per-criterion kappas — both `None` only with no comparable pairs / no kappa contributed. Aggregate + per-judge paths share one helper **`_criterion_level_scalars(...)`** (`_compute.py`; binary label/MET flats, falls back to multi-choice exact-match with no binary criterion); `_mean_or_none(values)` is the None-safe mean. The constructor wraps each scalar `x if x is None else float(x)`.

**Per-judge metrics mirror the aggregate's type handling field-for-field.** `_compute_judge_metrics` collects binary `cr.votes` and multi-choice `cr.multi_choice_votes` (records each judge's `selected_index` per item, NA-normalized via the SAME `effective_criteria` as the aggregate, captures the matching vote's `error` so errored MC votes skip with binary parity). It builds each judge's per-criterion kappas by reusing the aggregate's exact construction — binary `cohen_kappa_score` on prepared label reps (appended only when label pairs exist), ordinal `_compute_ordinal_criterion_metrics(...).weighted_kappa`, nominal `_compute_nominal_criterion_metrics(...).kappa` (appended after `filter_na_multi_choice`) — then calls `_criterion_level_scalars`. **Invariant: a 1-judge "ensemble" yields `per_judge[only]` equal to the aggregate field-for-field** (accuracy, mean_kappa equal; P/R/F1 both-None-or-equal; **and `phi` equal** — see below). `JudgeMetrics` widened its five scalar fields to `float | None`.

Each judge also gets `phi` and a `confusion_matrix`. The per-judge `confusion_matrix` is a 3×3 `ConfusionMatrix` with labels `["MET", "UNMET", "CANNOT_ASSESS"]` (the abstain class last), built by `_build_binary_judge_confusion_matrix` from the judge's **RAW pre-`cannot_assess`-filter** binary verdicts **pooled across all binary criteria** (errored/type-mismatched cells already dropped, but CANNOT_ASSESS abstentions preserved as their own class so filtering cannot hide them). Because every judge uses the same fixed class order, the aggregate of per-judge matrices is their elementwise sum; it is `None` when the judge contributed no binary verdict pairs (no data → no matrix, never a fabricated all-zero matrix).

### Matthews correlation (φ) and macro/micro aggregates
`_mcc_or_none(met_true, met_pred)` is the single helper for the φ coefficient (Matthews correlation) on the binary MET-vs-rest dichotomy. It carries a **mandatory `len(set(...)) < 2 → None` guard on either side** because `matthews_corrcoef` silently returns a misleading `0.0` on constant/single-class input; a NaN result likewise maps to `None`. φ equals Cohen's κ on matched (balanced) marginals and exceeds it as the positive-rate marginals drift apart (e.g. the 2×2 `[[40,10],[20,30]]` gives κ≈0.400, φ≈0.408).

`_criterion_level_scalars` was widened from a 5-tuple to `(accuracy, precision, recall, f1, mean_kappa, phi, micro_kappa)`, computing **micro** φ (`_mcc_or_none` over the pooled binary MET flats) and **micro** Cohen's kappa (`_kappa_or_none` over the pooled binary label reps) from the SAME flats — so the aggregate `criterion_phi`, the per-judge `JudgeMetrics.phi`, and the bootstrap path all bind to one source and a 1-judge ensemble's φ equals the aggregate's by construction. Both are `None` for a multi-choice-only rubric (no MET class) and `None` on degenerate single-class pooled data. The aggregate also exposes `macro_accuracy` (unweighted mean of per-criterion `accuracy`/`exact_accuracy` via `_mean_or_none`), `micro_kappa` (the pooled value above, distinct from the macro `mean_kappa`), and `mean_krippendorff_alpha` (macro mean of the per-criterion α). Each binary `CriterionMetrics` carries a 2×2 `ConfusionMatrix` (labels `["MET","UNMET"]`) built by `_build_binary_2x2_confusion_matrix`, plus `fpr`/`fnr` taken from that matrix's undefined→None properties, per-criterion `phi`, and `is_degenerate` (True iff it had samples but `kappa is None`); ordinal/nominal set `is_degenerate` on `weighted_kappa is None` / `kappa is None`.

`compute_metrics` appends two diagnostic warnings: a **score-collapse** warning when the per-item ground-truth scores take ≤2 distinct values (rank correlations on a collapsed range are uninformative), and a **degeneracy** warning naming the criteria whose agreement coefficient collapsed to `None` despite having samples.

### Rendering: `summary()` / `to_dataframe()` and the single-source notes

`MetricsResult.summary(*, verbose=False)` and `to_dataframe()` (`_types.py`) are the **only** surfaces that render the conflation / cluster / geometry / φ-gap notes — these notes live here (and in the field docstrings), never in `meta/_display.py`. Both render through the module-level None-safe formatter **`_fmt_opt(value, spec, width=0)`**, which shows `None` as right-aligned `'n/a'`.

`summary()`:

- **Handling-modes line** — `Handling modes: CANNOT_ASSESS=<cannot_assess_mode>, NA=<na_mode>`, so every accuracy/kappa/F1 carries its estimand (a number reported without its handling mode is ambiguous among the three estimands).
- **Micro/macro labels** — the criterion-level block names each scalar's aggregation level: `Accuracy (micro)` / `Accuracy (macro)` / `Precision (micro)` / `Recall (micro)` / `F1 (micro)` / `Mean Kappa (macro)` / `Kappa (micro)` / `Phi (micro)` / `Mean Kripp-α (macro)`. Binary-only P/R/F1 and `Phi (micro)` render only when at least one binary criterion exists.
- **Score block** — header reads `Score-Level Metrics (continuous per-item weighted score):` to declare the scale (these are not binary-verdict correlations).
- **φ cluster + conflation note** — `Phi (micro)` sits in the κ cluster with the single-source note that on binary data φ = Pearson = Spearman = Kendall = MCC and the κ − φ gap is the judge's positive-rate drift (not extra evidence).
- **Type-aware inter-judge rendering** — for **binary/nominal** criterion groups Krippendorff's α is the single primary column and the **bare Fleiss column is dropped** (they coincide up to a finite-sample correction `(1 − κ_F)/(N·R)`); a single conflation note explains the omission (the note may name Fleiss, but no Fleiss data column is rendered). For **ordinal** groups both α (distance-aware) and Fleiss (nominal) are kept with a **different-geometry** note (a distinguishing note, not a conflation note).
- **Binary confusion cells + coverage continuation** — each binary row shows `Phi`, `FP`, `FN`, `FPR`, `FNR` (from `CriterionMetrics.confusion_matrix` / `.fpr` / `.fnr`); under the `exclude` mode an aggregate **Coverage** continuation line renders the `coverage_stats` (coverage %, judge/gt abstain rates, errored count).
- **Degenerate vs no-data** — a criterion with `is_degenerate=True` (samples present, agreement undefined) is suffixed with a distinct `[degenerate: ...]` marker, not silently shown as `n/a` like a no-data (`n_samples==0`) criterion.
- **Per-judge swap + `verbose`** — the default per-judge line leads with the chance-corrected `Acc` + `Mean Kappa` + `Phi` (was RMSE + Spearman). The keyword-only `verbose=True` flag adds the secondary numeric columns (RMSE, Spearman, MAE) and prints each judge's confusion matrix; the default omits both.

`to_dataframe()` aggregate-row keys are **level-labelled** — `accuracy_micro` / `precision_micro` / `recall_micro` / `f1_micro` / `kappa_micro` / `phi_micro` (pooled) and `accuracy_macro` / `mean_kappa_macro` (unweighted means), plus `mean_krippendorff_alpha`, the handling modes (`cannot_assess_mode` / `na_mode`), `n_samples`, and the coverage columns (`coverage` / `judge_abstain_rate` / `gt_abstain_rate` / `union_exclusion_rate` / `n_errored` / `error_rate`; `None` outside exclude mode). The former bare `accuracy` / `precision` / `recall` / `f1` / `kappa` columns are **removed** (they mixed levels). Per-criterion rows add `phi` / `fpr` / `fnr` / `is_degenerate` and the coverage columns; the bare `fleiss_kappa` value is emitted only for ordinal criteria (binary/nominal leave it `None` — α primary). Per-judge rows add `phi`. The store tolerates `None` (emits JSON null / NaN). The handling modes round-trip through `to_file` (they are frozen fields, serialized by `model_dump_json`).

### "Undefined → `None`, never a fabricated `0.0`" — the cross-cutting invariant
A single principle across grading → metrics → improvement loop: **a metric / statistic / score / coefficient is `None` when genuinely undefined (no data, degenerate input, computation failed, or not-applicable), never a stand-in `0.0`/`1.0`.** Counts (`n_samples`, `support_*`, confusion cells) stay `0`; aggregates average only defined values (`_mean_or_none`) and are `None` if none defined; renderers show `None` as `n/a` and never crash. Modeled on the pre-existing `na_kappa`/`ca_kappa`/`BiasResult.{p_value,effect_size,ci}` handling. Applies to:

- **Kappa (Cohen's, all paths).** `_kappa_or_none(y1, y2, *, weights=None)` (`_compute.py`) is the single helper for every pred-vs-truth Cohen's kappa (binary per-criterion, ordinal `weights="quadratic"`, nominal, per-judge). Returns `None` on exception **or a NaN result** (degenerate single-class data makes `cohen_kappa_score` return NaN with no exception; the old `except: 0.0` let it leak). `None` kappas are excluded from `mean_kappa` via `_mean_or_none`.
- **Empty-data criteria.** With zero usable paired samples, a criterion's metric values (`accuracy`/`precision`/`recall`/`f1`/`kappa`, ordinal `exact_accuracy`/`adjacent_accuracy`/`weighted_kappa`/`rmse`/`mae`, nominal `exact_accuracy`/`kappa`, `OptionMetrics.precision/recall/f1`) are `None`; only counts stay `0`. `_compute_adjacent_accuracy([])` returns `None`.
- **Correlations.** `_compute_correlation` returns `CorrelationResult.coefficient = None` (and `p_value = None`) for `<3` samples (`interpretation="insufficient data"`) or a constant array (NaN → `interpretation="undefined"`); `_interpret_correlation` is only called with a real float. `validate_ground_truth`'s Spearman likewise yields `None` on a constant rubric-score array. Since the constant-array case is handled, scipy's spurious `ConstantInputWarning`/`NearConstantInputWarning` is suppressed locally around the `spearmanr`/`kendalltau`/`pearsonr` calls.
- **Distribution (`distribution.py`).** `score_distribution` returns `None` for stats undefined at the sample size (`std`/`variance` at n<2, `skewness` at n<3, `kurtosis` at n<4, all central-tendency at n=0); a single point keeps its computable `mean/min/max/median/iqr`. `earth_movers_distance` on empty input returns `None` fields.
- **Bias (`distribution.py`).** `systematic_bias` computes `mean_bias` at n=1 (the single difference) with `std_bias=None`; at n=0 both `None`; `effect_size` is `None` when `std_bias == 0` (Cohen's d undefined). `BiasResult.{mean_bias,std_bias}` are `float | None`.
- **Inter-judge agreement.** `validate_agreement` returns `None` (not `0.0`) when no usable sample was measured; the empty-rubric grader path sets `EnsembleEvaluationReport.mean_agreement = None` (`float | None`, default `None`); improvement-loop consumers (`pareto_accept`, `_check_convergence`, best-tracking, formatting) treat `None` as "not measured".
- **Bootstrap (item-level, all rubric types).** `_compute_bootstrap_ci` resamples **items** (one shared index applied across all criteria), recomputing the SAME reported aggregates per replicate via the shared `_per_criterion_kappas` + `_criterion_level_scalars` helpers (also used by `_compute_judge_metrics`), so `accuracy_ci`←`criterion_accuracy`, `kappa_ci`←`mean_kappa` (ordinal contributes quadratic-weighted kappa), `rmse_ci`←`score_rmse` — for binary, multi-choice, AND mixed rubrics (was binary-only: gated behind flattened binary labels, so pure multi-choice silently returned `bootstrap=None` and even lost `rmse_ci`). `_per_criterion_kappas` is the single source of truth for the per-criterion kappa list (binary Cohen on label reps appended only when label pairs survive; ordinal/nominal via `_kappa_or_none(..., weights=...)` on `filter_na_multi_choice`-filtered indices — the same primitive the metric functions use, so values match the aggregate without building throwaway metric objects per resample). **Two independent resample axes** (verdict-item for accuracy/kappa, scored-item for rmse) → marginal CIs. `effective_criteria` is fixed once on the full sample (re-deriving per resample would jitter the NA index space / ordinal weight matrix). `BootstrapResults.{accuracy_ci,kappa_ci,rmse_ci}` are `tuple[float, float] | None` — `None` when the axis is empty or every replicate is degenerate (single-class → per-criterion kappa `None` → empty `kappa_samples`); a single scored item gives a degenerate `(v, v)` rmse CI (RMSE is defined n≥1). `summary()` skips a `None` CI line (bootstrap is not in `to_dataframe()`). The old binary path used **pair-flattening** (treats criteria within an item as independent → anti-conservative); item-level CIs are wider/correct, and the kappa CI now brackets the reported `mean_kappa` (the old per-binary pooled Cohen value bracketed no reported statistic). Spurious single-class sklearn warnings are suppressed locally around the resample loop.
- **Grade-failure score.** `EvaluationReport.score`/`raw_score` and `EnsembleEvaluationReport.score`/`raw_score`/`llm_raw_score` are `float | None`; `None` emitted **only** on the explicit failure constructors (`EvalRunner._create_error_report`, the grader's "No judge results to aggregate" report). The normal path always computes a real float, and the scoring core never reads `report.score`. Consumers filter `error is not None` first or are `None`-guarded: `EvalResult.get_scores()` filters `score is not None`; the length-penalty path (`graders/base.py`) returns an errored report unchanged; `compute_metrics` **excludes** an errored/`None`-score report from score-level RMSE/correlation/bias arrays (no `0.0` substitution); `meta/_display` renders `None` as `n/a`; `validate_ground_truth` and the improvement loop raise `RuntimeError` on a *structural* grade failure (no score). Serialization round-trips `None` cleanly (writers coercion-free; readers index/`.get` without `float()`/`0.0` defaults).
- **Extraction failure.** `extract_all_verdicts_from_report` returns `None` for any criterion whose verdict can't be extracted — including the whole-report `report.report is None` branch (reachable from the grader's score-less "No judge results to aggregate" report) — for BOTH binary and multi-choice, never a fabricated multi-choice option `0`. The consumer then maps binary `None` → `UNMET` (conservative default) and multi-choice `None` → the effective NA index, so a failed extraction is an abstain rather than a spurious option-0 vote that would corrupt per-criterion kappa / per-option support / NAStats / na_kappa.
